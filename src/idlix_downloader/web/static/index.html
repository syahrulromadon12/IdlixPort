Sesi IDLIX opsional Tanpa akun

Login berlangsung di situs IDLIX. Pilih profil browser yang sama dengan tempat kamu login.

Belum ada profil browser yang dapat dibaca di mesin backend. Mode tanpa akun tetap tersedia.

Cookies hanya berada di memori. Izin OS/Keychain mungkin muncul. Aplikasi tidak meminta password IDLIX dan tidak melakukan logout browser.

Buka situs IDLIX pada profil pilihan, lalu kembali ke tab ini. Profil tab baru tidak dapat dipastikan otomatis. Jika browser aplikasi berbeda, salin alamat dan buka sendiri pada browser/profil yang dipilih.

Halaman IDLIX atau tautan MP4, HLS, dan DASH yang didukung.
