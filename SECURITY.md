# Security

Gunakan fitur **Report a vulnerability** pada tab Security repositori jika
tersedia. Jika belum tersedia, minta kanal privat melalui issue tanpa
menyertakan detail sensitif atau reproduksi kerentanan.

Sertakan versi atau commit, platform, dampak, dan langkah reproduksi yang memakai
data sintetis. Hapus cookies, token, URL bertanda tangan, dan path pribadi dari
log. Aplikasi web dirancang untuk penggunaan lokal melalui loopback.
